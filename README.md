# Anna English Tutor — лендинг репетитора английского

Одностраничный сайт для репетитора английского языка онлайн. React 19 + Vite + Tailwind 4. Заявки с формы уходят на email через Web3Forms и, опционально, в Google Таблицу через Apps Script. Статика, заточенная под Netlify.

## Какую задачу решает

Воронка «посетитель → заявка на бесплатный пробный урок»: объясняет подход к обучению, снимает возражение «не знаю свой уровень» и даёт одну очевидную точку записи.

## Для кого

- Репетиторы и языковые школы, которым нужен лендинг с формой записи и без бэкенда.
- Фрилансеры-преподаватели, которые сами ведут приём заявок.
- Разработчики — как шаблон статического лендинга с готовой интеграцией форм.

## Функции

- **Секции:** Hero, About, Programs (4 программы), Benefits (5 преимуществ), Process (4 шага), StudyBanner, Reviews, Contact, Footer.
- **Форма записи:** имя, контакт, цель. Валидация телефона (10–20 цифр) и Telegram (`@username`). Состояния загрузки, тост-успех на 6 секунд, очистка формы.
- **Антиспам:** скрытое honeypot-поле — боты игнорируются.
- **Отправка в два канала** (`src/lib/submitLead.js`): Google Apps Script для таблицы и Web3Forms для письма. Каналы независимы — сбой одного не блокирует другой. Без ключа форма работает в демо-режиме.
- **Анимации появления** секций через `IntersectionObserver` (компонент `Reveal`), с задержкой.
- **Адаптив:** липкий хедер, меню-бургер на мобильных.
- **Доступность:** skip-link, ARIA у меню и модалки, `prefers-reduced-motion`.
- **SEO:** метатеги и Open Graph, `netlify.toml` для деплоя.

## Технологии

React 19, Vite 8, Tailwind CSS 4, `@vitejs/plugin-react`, lucide-react, Web3Forms, Google Apps Script + Google Sheets, Netlify.

Стейт-менеджмента и CSS-in-JS нет — состояние локальное, через `useState`.

## Установка и запуск

Требуется Node.js 20.19+ и npm 10+.

```bash
npm install
cp .env.example .env     # Windows: copy .env.example .env
npm run dev              # http://localhost:5173
```

Сборка и предпросмотр:

```bash
npm run build            # → dist/
npm run preview
```

### Переменные окружения

Обе необязательные, файл `.env` под `.gitignore`:

```ini
VITE_WEB3FORMS_ACCESS_KEY=   # ключ с web3forms.com — отправка на email
VITE_SHEETS_ENDPOINT=        # URL /exec из Apps Script — запись в таблицу
```

Пустое значение = канал отключён. Переменные `VITE_*` вшиваются в клиентский бандл, поэтому они публичные — не используйте здесь серверные токены.

**Запись в Google Таблицу:** создайте таблицу → «Расширения → Apps Script» → вставьте `apps-script/Code.gs` → Deploy → Web app, доступ «Любой, у кого есть ссылка» → скопируйте URL с `/exec`. Проверка: запустите `testWebhook()` в редакторе скрипта.

**Деплой на Netlify:** подключите репозиторий, настройки уже в `netlify.toml`. Переменные задаются в Site configuration → Environment variables. После их изменения нужен перезапуск деплоя — значения зашиваются на этапе сборки.

| Команда | Действие |
| --- | --- |
| `npm run dev` | Dev-сервер с HMR |
| `npm run build` | Продакшен-сборка в `dist/` |
| `npm run preview` | Предпросмотр сборки локально |

## Ограничения

- Тексты захардкожены в компонентах: нет CMS и локализации.
- **Отзывы вымышлены** (результаты IELTS, рейтинг 4.9) — заменить или удалить до запуска.
- **Контакты — заглушки**: `anna.tutor@example.com`, `+7 900 123-45-67`.
- Изображения и шрифты грузятся с Unsplash и Google Fonts по CDN.
- Нет CRM, тестов, линтера и CI.
- Антиспам только honeypot; Apps Script-эндпоинт публичный.
- Ключи `VITE_*` попадают в бандл — для скрытых ключей нужен серверный прокси.
